# Guards levels and Gold Pass (inferred, never stored)

- **Guards level is never read off a screen — it is inferred from donations.** Omen Essence lines are exact multiples of a per-level unit (G7 11,000, G8 14,300, G9 18,600 — ×1.3 per level; a full donation is 70 units), and Scientific Tractates come in one fixed amount per level (15M G7, 58M G8, 76M G9). The ladder lives in [guards-ladder.ts](../src/config/guards-ladder.ts) with a build-time guard test; checked against ChestTracker's hand-entered levels it agreed for 116 of 131 members, and nearly every miss was ChestTracker lagging behind a level-up.
- **The level is computed on every read, never stored** ([guards-estimator.ts](../src/data/guards-estimator.ts)): the best non-decreasing level path through a member's dated evidence. Same reasoning as hero level — a stored value would bake in one bad high read. The only table is `member_guards_reports` (v75): an admin's dated entry, weighed as evidence, so later donations can still carry the member above it.
- **A 22,300 essence unit exists and is G9**, not G10 — every member who donates on it gives the G9 tractate tier. Cause unknown. A tractate tier *below* the member's level is a partial donation, not a demotion.
- **Gold Pass = Union Chest + an exact 250k Scientific Tractates line in the same Triumphal cycle** ([gold-pass-repo.ts](../src/data/repositories/gold-pass-repo.ts)). A pass-reward Union Chest donates exactly 250k on the day it is opened. Either on its own is not enough: Union Chests are also sold in the store. Union Chests are counted through `getEventBreakdown('triumphal', …)`, so the marker always matches the Events → Triumphal tab. The 250k line is not a guards tier and must never be read as one.
